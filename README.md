AdventureWorks SQL Projec

PROJECT OVERVIEW
This project focuses on analysing the AdventureWorks database using SQL. It demonstrates the use of SQL JOINs and Subqueries to answer business-related questions and extract meaningful insights from the database.

PROJECT OBJECTIVES
- Develop 15 original business questions based on the AdventureWorks database.
- Use SQL JOINs to answer 10 business questions.
- Use SQL Subqueries to answer 5 business questions.
- Practise writing structured and readable SQL queries.

TOOLS USED
- MYSQL WORKBENCH
- GitHub

PROJECT STRUCTURE
1. Business_Questions.docx – Contains the 15 business questions.
2. .sql file – Contains the SQL queries used to answer all 15 questions.

SQL TECHNIQUES
- INNER JOIN
- LEFT JOIN
- Other relevant JOIN types
- Subqueries
## Conclusion
This project demonstrates practical SQL skills in querying relational databases, solving business problems, and retrieving useful information from the AdventureWorks database.
